# Detailentwurf

Ordner für den Detailentwurf des Teilelager-Programms.

Geplante Dokumente (Status: noch nicht erstellt):

| Datei | Inhalt |
|---|---|
| `klassendiagramm.md` | Klassendiagramm der zentralen Klassen bzw. Module |
| `sequenzdiagramme.md` | Sequenz- oder Aktivitätsdiagramme für mindestens zwei zentrale Use Cases |
| `datenmodell.md` | Datenmodell (ER-Diagramm bzw. Schema) |
| `entwurfsprinzipien.md` | Angewandte Entwurfsprinzipien und gegebenenfalls Entwurfsmuster |
