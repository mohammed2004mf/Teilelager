# Architektur

Architekturdokumentation des Teilelager-Programms (Meilenstein `v0.2`, Issues #6 bis #9). Aufbau und Vorgehen folgen dem Architekturkapitel der Lehrveranstaltung: Qualitätsszenarien, Herleitung des Stils mit Attribute-Driven Design, Strukturen, UML-Diagramme, Entscheidungen als ADRs und Sichten nach dem 4+1-Modell.
