# Architektur

Ordner für die Architekturdokumentation des Teilelager-Programms.

Geplante Dokumente (Status: noch nicht erstellt):

| Datei | Inhalt |
|---|---|
| `architekturstil.md` | Gewählter Architekturstil mit Begründung und betrachteten Alternativen |
| `komponenten.md` | Komponentendiagramm mit Schnittstellen, bei Bedarf Verteilungsdiagramm |
| `adr/ADR-001-….md` ff. | Architecture Decision Records (Titel, Kontext, Entscheidung, Status, Konsequenzen), mindestens drei |
| `entscheidungen-und-nfr.md` | Welche Entscheidung unterstützt welche nichtfunktionale Anforderung |
