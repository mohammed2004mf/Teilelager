# Anforderungen

Ordner für die Anforderungsdokumente des Teilelager-Programms (Lehrveranstaltung Software Engineering, WS 2026/27).

Geplante Dokumente (Status: noch nicht erstellt):

| Datei | Inhalt |
|---|---|
| `vision.md` | Produktvision: Problem, Zielgruppe, Nutzen |
| `stakeholder.md` | Stakeholder und Nutzerrollen |
| `use-cases.md` | Use-Case-Diagramm und Use-Case-Vorlagen |
| `user-stories.md` | User Stories mit Akzeptanzkriterien |
| `nichtfunktionale-anforderungen.md` | Messbare Qualitätsanforderungen |
| `priorisierung.md` | Priorisierung (MoSCoW) mit Begründung |

Alle Anforderungen erhalten eindeutige IDs (`REQ-01`, `NFR-01`, `UC-01`, `US-01`), damit sie in der Traceability-Matrix (`../traceability.md`) verfolgt werden können.
